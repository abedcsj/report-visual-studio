원본 자료를 그래프로 바꾸는 방법

  1. 왼쪽에서 차트·도식을 고르고 ① 유형별 요청문 보기·복사를 누릅니다.
  2. 복사한 요청문과 원본 엑셀·표를 ChatGPT 대화에 함께 보냅니다. 이 사이트가 자료를 AI로 전송하지는 않습니다.
  3. ChatGPT의 변환 결과를 ② ChatGPT 답변 붙여넣기에 넣고 적용합니다. 제목·단위·출처·데이터가 한 번에 들어갑니다.
  4. 원자료와 그래프를 확인한 뒤 PNG·SVG로 저장합니다.

숫자 누락·단위 혼동·증감 합계 오류는 먼저 확인하세요. 예시 데이터는 사용법을 위한 가상 자료이며 보고서에 그대로 사용하면 안 됩니다.

기업을 선택하고 왼쪽 목차에서 본문·추가 확인 사항과 도식을 작성하세요. 변경사항과 사진은 이 브라우저에 자동 저장됩니다. 브라우저 데이터 삭제 시 사라질 수 있으므로 기업 작업 백업을 보관해주세요. 기존 온라인 사이트의 자료는 자동 이전되지 않습니다. 상단의 저장됨을 확인해주세요. 기업 전체 작업 다운로드는 초안·출처·메모·프롬프트·첨부파일·모든 도표를 하나의 JSON 파일로 보관합니다. 같은 이름의 기업을 선택하고 기업 작업 불러오기로 다시 가져올 수 있습니다.
