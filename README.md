# 기업분석 보고서 작업실 — GitHub Pages 버전

## 미리보기 확대·축소
미리보기 영역에서 트랙패드 또는 터치 화면의 두 손가락을 오므리면 축소하고 벌리면 확대합니다.
− / +, 배율 숫자 입력, 100%, 화면에 맞춤 버튼도 사용할 수 있습니다.
새 도식은 전체가 보이도록 맞추며 미리보기 배율은 PNG/SVG 출력 크기와 저장 자료를 바꾸지 않습니다.
preview-zoom.js와 preview-zoom.css를 포함한 파일 전체를 업로드해주세요.

## 항목별 전용 템플릿 수정
보고서 목차의 39개 선택 항목에 각각 별도의 유형 코드·예시·요청문을 제공합니다.
산업 범위는 범위를 좁히는 도식, 인과관계는 요인→경로→결과와 근거,
경쟁력·방어 요인·가치 유지·주요 이슈·최종 판단은 항목별 전용 열로 표현합니다.
기존 작업은 덮어쓰지 않습니다. 기존 항목에서 요청문을 다시 복사하거나 새 도식을 추가하세요.
수정 시 ZIP 안의 파일을 기존 저장소 최상위에 덮어쓰세요. section-templates.js도 반드시 포함해야 합니다.

서버 설치 없이 GitHub Pages에서 실행하는 버전입니다.

## 올리는 방법
1. ZIP 압축을 풀고 폴더 안의 모든 파일을 선택합니다.
2. GitHub의 abedcsj/report-visual-studio 저장소에서 Add file → Upload files를 엽니다.
3. 내용물을 드래그합니다. index.html이 저장소 최상위에 놓여야 합니다. 바깥 폴더 자체를 올리지 마세요.
4. Commit changes를 누릅니다. 이전 소스의 dist, worker 등은 남아 있어도 이 버전은 사용하지 않습니다.
5. Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save.
6. 배포가 완료되면 https://abedcsj.github.io/report-visual-studio/ 에 접속합니다.

## 저장 방식
- 기업별 본문·도표·제품 사진을 현재 브라우저의 IndexedDB에 저장합니다. 서버·로그인·DB 가입이 필요 없습니다.
- 브라우저나 컴퓨터가 다르면 자료가 공유되지 않습니다. 사이트 주소를 바꾸어도 별도 저장소로 취급됩니다.
- 브라우저 데이터 삭제, 비공개 창 종료, 저장 공간 정리로 자료가 없어질 수 있습니다. 작업 후 '기업 전체 작업 다운로드' JSON을 보관하세요.
- 다른 컴퓨터에서는 같은 기업명을 새로 만들고 '기업 작업 불러오기'를 사용합니다. 사진도 백업에 포함됩니다.
- 다른 탭의 변경과 충돌하면 저장을 중단합니다. 백업 후 저장본을 다시 여세요.
- 기존 온라인 사이트 자료는 자동 이전되지 않습니다. 기존 기업 작업 백업을 가져올 수 있지만 기존 서버 사진은 다시 첨부해야 합니다.
- 이 ZIP에는 실제 기업 보고서나 사진이 없습니다. 개인 백업 JSON은 GitHub 저장소에 올리지 마세요.

## 실행과 기능
별도 빌드가 필요 없습니다. index.html과 함께 있는 JS/CSS 파일 모두가 필요합니다.
DOCX 읽기에 필요한 mammoth.browser.js도 포함되어 있습니다.
기업 선택, 기업별 보고서 목차, 복수 도식, 제품 사진, 도표 크기 조절, PNG/SVG 내보내기를 유지합니다.
문서 추천은 규칙 기반이며 AI 서버로 전송하지 않습니다. 사이트 요청문을 복사해 ChatGPT에서 변환한 답변을 붙여넣는 방식입니다.

## 기업 전체 작업 다운로드와 복원
상단의 기본 다운로드는 현재 도식 하나가 아니라 선택한 기업의 전체 작업을 JSON 한 파일로 보관합니다.
- 모든 목차의 본문 초안, 조사 메모, 추가 확인 사항, 완료 상태
- 출처의 자료명·기관·기준기간·URL·페이지·근거 원문·해석
- 회사 공통 및 목차별 작성 프롬프트, 보고서 제목과 기준일
- 모든 도표·도식의 편집 데이터와 제품 사진
- 보관함에 추가한 첨부파일 원본 데이터
같은 이름의 기업을 선택하고 ‘기업 작업 불러오기’로 복원합니다. 기존 내용에 추가하므로 같은 파일을 반복해서 불러오면 내용이 중복될 수 있습니다. 다른 컴퓨터에서는 같은 이름으로 새 기업을 만든 뒤 불러오세요.
다운로드 파일은 특정 시점의 전체 작업 스냅샷입니다. 모든 과거 수정 버전의 기록은 아닙니다.
개별 PNG·SVG 및 표 내보내기는 보고서에 삽입할 때 사용하는 별도 기능입니다.

## 보고서 작성과 자료 보관
기업을 열면 ‘보고서 작성·자료’에서 목차별 본문과 조사 자료를 작성합니다.
첨부해주신 보고서 프롬프트를 기본값으로 포함했으며, 기업별 수정이 가능합니다.
Executive Summary와 실제 경쟁사 분석 목차를 추가했습니다. 기존 초과이익 방어 자료는 보조 조사 목차에 보존합니다.
‘자료를 포함한 작성 요청문 복사’는 해당 목차의 본문·출처·메모·도표 데이터를 모읍니다. 첨부파일 본문을 자동 분석하거나 AI에 전송하지 않습니다.
‘전체 초안 모아보기’에서 보고서 순서대로 본문을 모아 복사하거나 Markdown·HTML로 받습니다. HTML에는 도표 데이터가 편집 가능한 표로 포함되며, 모든 원본 자료의 완전한 보관에는 기업 전체 작업 JSON을 사용하세요.
항목 수에 임의 제한은 없으며 실제 저장 가능 용량은 브라우저 저장 공간에 따릅니다.

## 편집 가능한 표
도표·도식 화면의 ‘표로 내보내기’에서 Word용 표 복사 또는 Excel용 CSV를 선택합니다.
HTML 표 붙여넣기를 지원하는 문서 편집기에서 셀과 글자를 편집할 수 있습니다. 차트를 Office의 원본 차트 개체로 변환하는 기능은 아닙니다.
재무표는 기간별 열로, 여러 계열 추이는 계열별 열로 정리됩니다.

## 보고서 작업 공간 (이번 업데이트)
기업을 선택하면 전체 보고서를 작성하는 독립 화면이 열립니다. Executive Summary는 다른 항목과 같은 하나의 목차입니다.
- 각 목차에서 본문을 바로 수정하고 문단을 추가합니다. 기존 목차별 본문과 같은 데이터에 자동 저장합니다.
- 원문·조사 메모·출처·추가 확인 사항·작성 요청문·첨부자료는 각 목차의 자료 보관함에서 관리합니다.
- 기업 공통 프롬프트와 메모는 보고서 상단에서 수정합니다.
- ‘도표·도식 추가’ 또는 ‘도식 수정’으로 해당 목차의 도식 편집 화면에 이동합니다. ‘보고서 작업 공간으로’ 버튼으로 돌아오면 변경된 도식이 반영됩니다.
- 도식의 위치를 본문 앞 또는 특정 문단 뒤로 지정할 수 있습니다. 본문에서 빈 줄로 문단을 나눈 뒤 ‘문단 배치 갱신’을 누르세요.
- 보고서에서 제외한 도식도 기업 작업에는 남습니다. 원래 도식 또는 편집 가능한 표 표시를 선택할 수 있습니다.
- Executive Summary 전용 유형: 기업과 사업 요약, 지분·지배구조, 핵심 재무, 투자 하이라이트와 성립 조건. 별도의 예시·요청문과 본문 작성 형식을 제공합니다.

## 보고서 출력
- ‘출력 미리보기’: 편집 버튼을 제외한 본문과 도식을 확인합니다.
- ‘Word 다운로드’: 실제 .docx 파일을 생성합니다. 본문과 표는 편집 가능하며, 원래 도식은 PNG 이미지로 포함됩니다.
- ‘PDF·인쇄’: 브라우저 인쇄창에서 PDF로 저장을 선택합니다. A4, 배율 100%, 머리글·바닥글 해제를 권장합니다.
- PDF는 보고서의 본문 순서·도식 위치·내용을 유지합니다. Word는 설치된 글꼴과 프로그램에 따라 줄바꿈과 페이지 구분이 달라질 수 있습니다. 화면은 연속 스크롤이고 출력은 페이지 단위입니다.
- ‘출력에 조사 메모·출처·확인 사항 포함’을 선택하면 해당 자료도 본문 뒤에 출력됩니다. 첨부파일 원본과 프롬프트까지 보관하려면 ‘기업 전체 작업 다운로드’를 사용합니다.
- 임의의 문단·도식 수 제한은 없습니다. 매우 큰 자료의 처리 가능 범위는 브라우저 메모리와 저장 공간에 따릅니다.

## 기업 삭제
기업 목록의 ‘기업 삭제’를 누르고 해당 기업명을 정확히 입력합니다. 선택한 기업의 자료만 삭제됩니다.
필요하면 삭제 전에 기업을 열어 전체 작업 JSON을 내려받으세요. 다른 탭에서 수정한 경우 충돌을 확인하고 삭제를 중단합니다.
기존 브라우저 저장소 이름과 데이터 구조는 유지하므로 같은 사이트 주소에서 업데이트하면 기존 기업 자료를 계속 사용할 수 있습니다.

이 배포에는 브라우저용 docx 9.6.1 및 라이선스 파일이 포함됩니다. 별도 서버나 API 키가 필요하지 않습니다.
