# 기업보고서 사이트

버전 2026.09.17-13 · D번호 도식 전용

GitHub Pages에서 실행하는 정적 사이트입니다. 보고서 초안과 도식은 사용하는 브라우저에 저장합니다.

|---|---|

| D02 | 지배구조도 |

작성틀의 번호를 유지하므로 D04·D09·D11·D14는 없습니다. D15·D16은 추가한 도식입니다. 표·카드·수치 그래프와 이전의 전체 유형 선택은 제공하지 않습니다. 모든 목차에서 동일한 D번호 목록을 사용합니다.

## 사용 순서

1. 기업을 선택하거나 ＋ 버튼으로 추가합니다.
2. 보고서 초안 작업실에서 문단을 작성하고 ＋ 도표·도식 추가를 누릅니다.
3. D번호와 이름으로 도식을 선택합니다. 닫기를 누르면 초안에 그대로 머무릅니다.
4. 선택한 도식의 요청문을 복사해 원자료와 함께 ChatGPT에 전달합니다.
5. 받은 JSON을 붙여넣고 도식을 확인한 후 도식 저장을 누릅니다. 미리보기만으로 저장되지 않습니다.
6. 복사는 도식 이미지로 수행됩니다. 투명 배경 설정도 적용됩니다.

D15는 단계명 앞에 ★를 붙인 단계의 배경색을 강조합니다. D08의 입금 조건은 해당 단계 설명에 넣고 실제 회계정책에 따라 매출 인식 위치를 조정합니다. 예시 데이터는 실제 기업 사실이 아닙니다. 단계나 항목 수에 임의의 상한을 두지 않습니다.

## 보고서 초안과 보관

- 제목·목차·문단은 기업별로 자유롭게 편집합니다. 도식은 문단에 속합니다.
- 문단 및 도식을 위·아래로 이동하고 수정·삭제할 수 있습니다.
- 기업별 구성 적용에서 목차 목록 또는 company-report-structure-v1 JSON을 입력합니다. diagramTypes에는 위 D번호만 사용합니다.
- 기업 작업 다운로드 ZIP에는 report.html, draft.md, draft.txt, 도식 이미지, 첨부파일, project.json이 들어갑니다.
- 같은 버전의 ZIP, project.json 또는 report.html을 불러와 작업을 복원합니다. 제거된 옛 유형은 이 버전에서 지원하지 않습니다.
- 같은 도메인·경로·브라우저의 IndexedDB에 저장됩니다. 브라우저 데이터를 삭제하면 작업도 삭제될 수 있으므로 기업 작업 다운로드로 보관하세요.
