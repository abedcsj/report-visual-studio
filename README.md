# 기업분석 보고서 작업실

GitHub Pages에서 실행하는 정적 사이트입니다. 설치할 서버나 API 키는 없습니다.

## 이번 버전: 두 작업실의 역할 정리

- **보고서 초안 작업실**: 기업별 목차·문단·본문·출처·원문·메모·도식을 작성합니다.
- **도식/도표 작업실**: 도식 유형, 데이터, 글자, 디자인을 편집합니다. 보고서 작성·자료 탭을 없앴습니다.
- 양쪽 화면 왼쪽 위에 상대 작업실로 이동하는 버튼이 있고 화면 이름은 가운데에 표시됩니다.
- 문단의 `＋ 이 문단에 도표·도식 추가`를 누르면 **초안 화면 위에 선택 창만** 열립니다. 닫기 또는 Esc는 초안에 그대로 머무릅니다. 유형을 선택하면 도식/도표 작업실로 이동합니다.
- 도식/도표 작업실에서 기존 보고서 이동 탭이 있던 자리에 `＋ 도표·도식 추가`를 배치했습니다.
- 유형을 살펴보는 것만으로 저장되지 않습니다. `도식 저장`을 눌러야 보고서에 추가됩니다. 저장된 도식의 수정은 자동 저장됩니다.
- 보고서 포함/제외와 문단 위치 선택 메뉴는 없습니다. 도식은 `도식 수정`, `도식 삭제`, `↑ 위로 이동`, `↓ 아래로 이동`으로 관리합니다.
- 문단의 이동은 소속 도식을 함께 옮깁니다. 도식 이동은 같은 문단 안에서 순서를 바꾸고 끝에서는 이웃 문단으로 이동합니다.
- 목차 제목을 클릭하여 바로 수정합니다. 목차도 위아래 이동·추가·삭제가 가능합니다. 기업별 변경은 다른 기업이나 기본 서식에 영향을 주지 않습니다.
- 출처나 원문은 본문 또는 `자유 기록·첨부파일`에 형식 구분 없이 적습니다. 예전 출처·메모·확인 사항은 자유 기록에서 이어서 편집할 수 있습니다.
- 자유 기록은 출력 미리보기와 Word/PDF에도 해당 목차 본문 뒤에 표시합니다. 공통 작성 프롬프트와 기업 공통 메모는 출력 본문에 자동 삽입하지 않습니다.

## 시작과 저장

기업을 새로 만들거나 선택하면 보고서 초안 작업실이 열립니다. 기본 목차와 Executive Summary가 제공됩니다. Executive Summary는 다른 목차와 동일한 하나의 항목입니다. 빠진 기본 목차는 `＋ 기본 목차 가져오기`로 추가할 수 있습니다.

문단과 문단별 도식 개수에 임의 제한은 없습니다. 실질적인 저장·처리 용량은 브라우저에 따라 달라집니다.

자료는 현재 브라우저의 IndexedDB에 기업별로 저장됩니다. 서버에 업로드하거나 다른 기기에 자동 동기화하지 않습니다. 브라우저 데이터를 삭제하면 자료가 사라질 수 있습니다. 기존 사이트와 같은 주소·브라우저에서 덮어쓰면 기존 저장 자료를 계속 사용합니다.

`기업 전체 작업 다운로드`는 초안·목차 구성·문단과 도식 연결·출처·프롬프트·사진·첨부파일을 JSON 하나에 담습니다. 모든 과거 편집 이력이 아닌 다운로드 시점의 전체 작업입니다. 기업 작업 불러오기는 같은 이름의 기업에 내용을 합칩니다. 반복해서 가져오면 중복될 수 있습니다.

## 도식과 내보내기

유형별 요청문을 복사해 원자료와 함께 ChatGPT에 보내고 변환 답변을 붙여넣습니다. 사이트 자체가 AI에 자료를 전송하거나 AI 모델을 실행하지는 않습니다.

- 도식 글자나 표 셀을 두 번 클릭하면 해당 원본 항목을 수정합니다. 유형의 고정 열 이름은 해당하지 않습니다.
- `Word용 표`: 편집 가능한 표 복사 또는 .docx 다운로드. Office의 원본 차트 개체를 생성하지는 않습니다.
- `이미지로 저장`: 일반 PNG 파일로 저장합니다.
- `Word 다운로드`: 전체 초안을 .docx로 만듭니다. 본문과 표는 편집 가능하고 도식은 이미지입니다.
- `PDF·인쇄`: 브라우저 인쇄창에서 PDF로 저장합니다. A4, 배율 100%, 머리글·바닥글 해제를 권장합니다.
- 화면은 연속 스크롤이고 문서는 페이지로 나뉩니다. Word의 글꼴과 프로그램에 따라 줄바꿈과 페이지 구분이 달라질 수 있습니다.

SVG 내보내기, CSV 버튼, 보고서 첨부·도식 추천, 복제 버튼은 제공하지 않습니다. 미리보기는 확대·축소 및 화면 맞춤이 가능합니다.

도식·문단·목차를 삭제하면 하단의 `삭제 취소`로 마지막 삭제를 되돌립니다. 기업 전체 삭제는 기업 목록에서 기업명 확인 후 진행하며 전체 작업 백업을 먼저 권장합니다.

## GitHub Pages 배포

압축을 풀고 `report-visual-studio-pages` 폴더 **안의 모든 파일**을 저장소 최상위에 올립니다. `index.html`이 최상위에 있어야 합니다. 파일 이름과 상대 경로를 유지하세요.

저장소 Settings → Pages에서 Source는 Deploy from a branch, Branch는 main, 폴더는 /(root)로 설정합니다.

기존 Mac 체크아웃 업데이트 예시:

```bash
unzip -o ~/Downloads/report-visual-studio-pages.zip -d ~/Downloads/report-studio-update
cp -R ~/Downloads/report-studio-update/report-visual-studio-pages/. ~/GitHub/report-visual-studio/
git -C ~/GitHub/report-visual-studio add .
git -C ~/GitHub/report-visual-studio commit -m "초안과 도식 작업실 화면 및 이동 개선"
git -C ~/GitHub/report-visual-studio push origin main
```

Downloads에 동명 ZIP이 있다면 이번 파일로 교체한 뒤 실행하세요. 배포 완료 후 사이트에서 Command + Shift + R로 새로고침합니다. 사이트 주소: https://abedcsj.github.io/report-visual-studio/

이 배포에는 브라우저용 docx 9.6.1과 라이선스 파일이 포함됩니다.
