# 기업보고서 사이트 — 2026.09.17-11

GitHub Pages에서 사용하는 정적 사이트입니다. 별도 서버·API 키 없이 현재 브라우저의 IndexedDB에 기업별 작업을 저장합니다.

## 이번 수정

이미지 배경 투명을 켜면 도식 복사와 기업 작업 ZIP의 도식 이미지에 투명도가 유지됩니다. 도식 내부의 카드·도형·표 셀에 지정한 색상은 그대로 유지합니다. 기업 작업 다운로드 버튼은 일반 밝은 버튼으로 표시하고, 두 작업실에 홈 버튼을 추가했습니다. 홈은 작업을 저장한 뒤 기업 선택 첫 화면으로 돌아갑니다.

## 기업별 기본틀 적용

두 작업실의 **기업별 구성 적용**에서 선택한 기업의 목차와 작성 틀만 변경합니다.

1. 목차만 정할 때는 제목을 한 줄씩 붙여넣습니다.
2. 문단별 작성 안내·핵심 질문·추천 도식까지 정할 때는 **구성 변환 요청문 복사**를 누르고 원하는 구성과 함께 ChatGPT에 전달합니다. 받은 JSON을 붙여넣습니다. 사이트 자체가 AI를 실행하지는 않습니다.
3. **적용 내용 확인**에서 기존 목차를 새 목차와 연결합니다. 연결한 본문·문단·도식·첨부파일은 유지합니다.
4. **이 기업에 적용**을 누르면 새 순서와 이름으로 저장합니다. 연결하지 않은 목차에 기존 내용이 있으면 뒤에 보존하고, 빈 기본 목차만 빠집니다.

문단의 guide는 빈 입력칸의 작성 안내이며 보고서 출력에는 들어가지 않습니다. text에 입력한 내용은 실제 초안이 됩니다. 기존 내용이 있는 목차에는 새로운 작성 안내 문단을 추가하며 기존 글을 덮어쓰지 않습니다. 다른 기업과 새 기업의 공통 기본 서식은 바뀌지 않습니다. 작성 틀과 추천 도식 설정은 기업 작업 ZIP에도 함께 저장됩니다.

## 화면 구성

- 가운데에는 현재 화면 이름만 표시합니다: **보고서 초안 작업실** 또는 **도식/도표 작업실**.
- 오른쪽에는 기존 로고와 **기업보고서 사이트**, 버전 번호가 표시됩니다.
- 왼쪽 위는 두 작업실 사이의 이동 버튼입니다. 기업 선택 첫 화면에는 이 버튼을 표시하지 않습니다.
- 두 작업실의 상단 버튼 순서는 같습니다: **홈 / 지금 저장 / 기업 작업 다운로드 / 기업 작업 불러오기 / 기업 목록**.
- 목차의 폭·글자·선택 표시·추가 버튼, 상단 높이와 기본 글자 크기를 통일했습니다. 배경은 아이보리와 연한 초록색입니다.

## 기업 선택

첫 화면은 작은 정사각형 카드 목록입니다. 기업명 검색으로 찾고, 목록 옆 **＋**를 누르면 기업명을 입력하는 창이 열립니다.
작업 중 **기업 목록**은 현재 화면 위에 검색 가능한 선택 창을 띄웁니다. 다른 기업을 누르면 저장 후 해당 기업으로 이동합니다. 선택 창의 **기업 전체 화면**을 누르면 카드 화면으로 돌아갑니다.
기업 삭제는 카드의 작은 삭제 버튼을 누른 뒤 기업명을 확인합니다.

## 초안과 도식 편집

새 기업은 기본 서식으로 시작합니다. 목차 이름·순서·구성은 기업별로 변경할 수 있고 다른 기업에 영향을 주지 않습니다. **기본 목차 가져오기**는 빠진 기본 목차만 추가합니다.

보고서는 **목차 → 문단 → 문단에 속한 도식들** 구조입니다. 문단과 도식 개수에 임의 제한은 없습니다. 본문·출처·원문은 본문 또는 자유 기록에 구분 없이 적습니다. 이전 출처·메모도 자유 기록에서 이어서 편집합니다.

- 문단의 **＋ 이 문단에 도표·도식 추가**는 초안 화면 위에 선택 창을 엽니다. 닫기/Esc는 초안을 그대로 유지합니다.
- 유형을 선택해야 도식/도표 작업실로 이동합니다. 미리보기를 살펴보는 것만으로 도식이 저장되지는 않습니다.
- **도식 저장**을 누르면 해당 문단에 추가됩니다. 저장된 도식의 수정 내용은 자동 저장합니다.
- 도식 형식은 기존 표현 방식 목록에서 선택합니다. 별도의 Word용 표 창은 없습니다.
- 도식 도구는 **도식 저장 / 복사 / 삭제**입니다. 이미지로 저장·SVG·별도 Word/PDF 다운로드 버튼은 없습니다.
- **복사**는 현재 표를 편집 가능한 HTML 표로, 그 외 도식을 모양 그대로 PNG 이미지로 클립보드에 담습니다. 붙여넣는 앱의 지원에 따라 표시가 달라질 수 있습니다.
- 도식 글자나 표 셀을 두 번 클릭하면 원본 내용을 수정합니다. 유형의 고정 열 이름은 해당하지 않습니다.
- 목차·문단·도식은 **위로 이동 / 아래로 이동**으로 순서를 바꿉니다. 문단을 옮기면 소속 도식도 함께 옮깁니다. 도식은 문단 경계에서 이웃 문단으로 이동합니다.
- 도식·문단·목차를 삭제하면 하단의 **삭제 취소**로 마지막 삭제를 되돌릴 수 있습니다.
- 보고서 포함/제외 및 본문 앞/몇 번째 문단 뒤 같은 위치 선택 기능은 없습니다.

## 기업 작업 다운로드와 불러오기

**기업 작업 다운로드**는 `기업명_기업작업.zip` 하나를 만듭니다. 압축 안에는 다음 자료가 있습니다.

| 파일 | 용도 |
| --- | --- |
| report.html | 브라우저에서 본문·표·도식을 함께 열어보는 초안. 이미지가 파일 안에 들어 있어 단독으로도 열립니다. |
| draft.txt / draft.md | 보고서 작성에 전달할 텍스트 초안 |
| visuals/ | 모양을 유지한 도식 이미지 |
| tables/ | 편집 가능한 표 HTML |
| attachments/ | 보관한 원본 첨부파일 |
| project.json | 목차·문단·도식 연결·편집 데이터·사진·프롬프트 등 전체 작업 복원 데이터 |

나중에 보고서 작성을 요청할 때는 **기업 작업 ZIP 전체를 첨부**하면 됩니다. 표와 도식의 원본 표현 및 편집 데이터가 함께 남습니다.

**기업 작업 불러오기**는 기업 작업 ZIP, ZIP 안의 project.json, report.html 및 기존 버전의 기업 전체 JSON을 지원합니다.
파일을 선택하면 기업명과 도식 수가 표시됩니다. **기존 기업의 작업 복원**은 현재 내용을 파일 내용으로 교체하고, **새 기업으로 가져오기**는 별도 기업에 보관합니다. 같은 작업을 반복 복원해도 도식이 계속 중복 추가되지 않습니다. 잘못된 파일은 변경 전에 거절합니다.

ZIP을 풀지 않고 사이트에 바로 불러올 수 있습니다. Mac 등에서 ZIP을 다시 압축했을 때 브라우저가 압축 방식을 지원하지 않는다면 압축 안의 project.json을 선택하세요.
파일을 더블클릭했을 때 Claude 등 어떤 프로그램이 열리는지는 컴퓨터의 기본 연결 앱에 따릅니다. 이 사이트는 파일을 Claude나 다른 AI 서비스로 자동 전송하지 않습니다. 초안은 report.html을 브라우저로 열어보세요.

## 저장과 호환

- 기존과 같은 사이트 주소·브라우저를 사용하면 기존 IndexedDB 자료를 유지합니다.
- 브라우저 데이터를 지우면 저장 자료가 사라질 수 있으므로 기업 작업 ZIP을 보관하세요.
- ZIP은 다운로드 시점의 전체 작업이며 모든 과거 수정 이력을 모은 파일은 아닙니다.
- JS·CSS 주소에 내용별 버전을 붙여 업데이트 후 이전 파일이 캐시에 남는 문제를 줄였습니다. 오른쪽 로고 아래 **2026.09.17-11**로 이번 버전을 확인합니다.
- 저장·이동·복사 형식·ZIP 내보내기·기존/새 기업 복원·잘못된 파일 거절을 DOM/IndexedDB 환경에서 검증했습니다. 도식 PNG는 실제 생성해 확인했습니다. 실제 Chrome UI 및 Word 붙여넣기는 이 실행 환경에서 직접 검증하지 못했습니다.

## GitHub Pages 업데이트

압축 안 `report-visual-studio-pages` 폴더의 **내용 전체**를 저장소 최상위에 올립니다. index.html과 JS/CSS 파일을 함께 교체하세요.

Mac의 Downloads에 동명 ZIP이 있다면 이번 파일로 교체한 뒤 실행합니다.

```bash
unzip -o ~/Downloads/report-visual-studio-pages.zip -d ~/Downloads/report-studio-update
cp -R ~/Downloads/report-studio-update/report-visual-studio-pages/. ~/GitHub/report-visual-studio/
git -C ~/GitHub/report-visual-studio add .
git -C ~/GitHub/report-visual-studio commit -m "기업 검색과 통일된 작업실 및 전체 작업 ZIP 적용"
git -C ~/GitHub/report-visual-studio push origin main
```

GitHub Settings → Pages: Deploy from a branch / main / /(root).
배포 완료 후 https://abedcsj.github.io/report-visual-studio/ 에서 Command + Shift + R로 새로고침하세요.
